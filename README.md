# Preview Server — Vercel

Автоматическая генерация превью с русскими OG-тегами для Telegram.

## Как деплоить

1. Залить эту папку в GitHub Bokov777 (отдельный репозиторий)
2. Зайти на vercel.com → Add New Project
3. Выбрать репозиторий
4. Нажать Deploy — всё настроено в vercel.json

## Как работает

Когда бот публикует новость:
1. Сохраняет превью (заголовок, выжимка, ссылка) на основном сервере
2. В сообщение вставляется ссылка: `https://preview.vercel.app/p/ARTICLE_ID`
3. Telegram запрашивает эту страницу → получает OG-теги на русском
4. Показывает превью с кнопкой «Посмотреть» на русском языке

## Структура
```
api/p/[id].js  — главный обработчик превью
public/        — статика (если нужна)
vercel.json    — настройки Vercel
```
